# Excel & VBA

Repositório de estudos, automações em VBA e guia rápido de atalhos e funções do Microsoft Excel.

## Stack
- **Planilhas:** Microsoft Excel (`.xlsx`, `.xlsm`)
- **Automações:** VBA (Visual Basic for Applications)
- **Referência rápida:** Planilha de consulta de atalhos e funções (`Atalhos_Excel_v2.xlsx`)

## Estrutura
```
cursos/          → exercícios, projetos e anotações dos cursos realizados
vba-automacoes/  → macros, módulos (.bas) e planilhas automatizadas (.xlsm)
guias/           → planilhas de consulta rápida, atalhos e funções
```
Cada pasta separa o conteúdo por finalidade: prática guiada (`cursos`), rotinas reutilizáveis (`vba-automacoes`) e consulta no dia a dia (`guias`).

## Como usar

### Planilha de atalhos e funções
1. Abra o arquivo `Atalhos_Excel_v2.xlsx` no Microsoft Excel.
2. Navegue entre as três abas conforme a necessidade:
   - **`Em uso`**: atalhos mais utilizados no dia a dia (linhas, formatação e navegação).
   - **`Excel`**: lista completa de combinações com a tecla `Ctrl`.
   - **`FUNÇÕES EXCEL`**: catálogo de funções (`TEXTO`, `SE`, `PROCV`, `PROCX`, `ARRUMAR`, `SUBSTITUIR`, entre outras) com sintaxe e exemplos combinados.

### Automações em VBA
1. Abra uma planilha `.xlsm` em `vba-automacoes/` e habilite o conteúdo de macros quando solicitado.
2. Para importar um módulo `.bas` em outra pasta de trabalho, pressione `Alt + F11` para abrir o Editor do VBA, clique com o botão direito no projeto e selecione **Importar Arquivo**.

## Regras do projeto
- Nunca subir planilhas com dados pessoais, financeiros reais ou informações corporativas (usar sempre dados fictícios nos exemplos).
- Salvar planilhas com macros no formato `.xlsm` e manter uma cópia dos módulos reutilizáveis em `.bas` dentro de `vba-automacoes/`.
- Comentar no início de cada macro o que ela faz, quais colunas/abas espera e como executá-la.
